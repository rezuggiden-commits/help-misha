# Поможем Мише — сайт благотворительного сбора

Готовый статический сайт для сбора средств на лечение ребёнка. Работает без сервера и базы данных: все данные лежат в одном файле `config.js`, а сайт публикуется бесплатно на GitHub Pages по HTTPS.

**Живой сайт:** https://rezuggiden-commits.github.io/help-misha/

---

## Как обновлять сайт (главная инструкция)

Все тексты, суммы, реквизиты и фотографии меняются **в одном файле — [`config.js`](config.js)**. Внутри он подробно подписан комментариями.

### Способ 1 — прямо в браузере (самый простой)

1. Откройте https://github.com/rezuggiden-commits/help-misha и войдите в аккаунт.
2. Выберите файл `config.js` → нажмите на **карандаш** (Edit) справа вверху.
3. Исправьте нужные строки (текст в кавычках, числа — без пробелов).
4. Нажмите **Commit changes** (сохранить).
5. Через 1–2 минут сайт обновится автоматически. Страницу лучше обновить с очисткой кэша (Ctrl+F5).

### Что чаще всего меняют

| Что | Где в `config.js` |
|---|---|
| Сколько собрано / цель | `fundraising.raised` и `fundraising.goal` (числа в рублях) |
| Текст истории | `child.shortStory` (короткий) и `story` (полный, по абзацам) |
| Фотографии | списки `slider` и `gallery` |
| Реквизиты (карта, счёт, СБП) | раздел `donate` |
| Контакты (телефон, Telegram, WhatsApp, почта) | раздел `contacts` |
| Отчёты о тратах | список `reports` (новые добавляйте сверху) |
| Кто организует сбор (для футера) | раздел `legal` |

### Фотографии

1. На GitHub откройте папку `img` → **Add file → Upload files** → загрузите фото (например, `photo-7.jpg`).
2. В `config.js` допишите `"img/photo-7.jpg"` в список `gallery` (и `slider`, чтобы фото попало на главную).
3. Сохраните. Рекомендуемый размер фото — до 1600 px по ширине, JPG.

### Отчёты с чеками

1. Загрузите фото чека/выписки в папку `img` (например, `receipt-2026-10.jpg`).
2. В `config.js` добавьте **в начало** списка `reports` новый блок:

```js
{
  date: "2026-10-01",
  title: "Название отчёта",
  text: "Короткое описание: что оплачено и на какую сумму.",
  image: "img/receipt-2026-10.jpg",   // или "" если без документа
},
```

### Отключить баннер «Режим настройки»

Пока в `config.js` стоит `demo: true`, сверху сайта виден жёлтый баннер о шаблонных данных. Когда замените все данные на настоящие — поставьте `demo: false`.

## Способы оплаты, которые уже подключены

Все три способа уже оформлены на сайте (открываются по кнопке «Помочь» и в разделе «Как помочь»):

1. **СБП по QR-коду** — наведённая камера открывает перевод. QR сейчас — заглушка (`img/sbp-qr.png`).
   **Как заменить:** в приложении вашего банка откройте «Получить перевод по СБП» → «Показать QR» → сохраните его как картинку → загрузите в `img/` вместо `sbp-qr.png`. Если банк даёт ссылку вида `https://qr.nspk.ru/...` — вставьте её в `donate.sbp.link`, и на сайте появится кнопка «Оплатить по ссылке СБП».
2. **На карту** — номер карты + телефон для перевода по СБП, с кнопкой «Скопировать». Замените в `donate.card`.
3. **По реквизитам** — получатель, счёт, банк, БИК, ИНН, назначение платежа. Замените в `donate.requisites`. Ненужные поля можно удалить.
4. **ЮMoney** (необязательно) — включите в `donate.yumoney` и вставьте ссылку с yoomoney.ru.

### Честно о полноценном эквайринге

Приём платежей «как в интернет-магазинах» (виджет ЮKassa, CloudPayments, Robokassa, Тинькофф) требует **договора с платёжным провайдером** и, как правило, статуса ИП / ООО / самозанятого (либо договоров с фондом). Это не делается за пять минут и без документов. Сейчас сайт использует честную и удобную схему: **СБП QR + карта + реквизиты** — деньги приходят напрямую получателю, без комиссий посредников.

Если позже появится ИП/самозанятость или договор с фондом: зарегистрируйтесь у провайдера (например, ЮKassa), получите ссылку/виджет и добавьте его в `donate` (по образцу блока `yumoney`) — структура это позволяет.

## Локальный запуск (по желанию)

Сайт — просто набор HTML-файлов. Можно открыть `index.html` двойным кликом, а лучше:

```bash
cd site
python -m http.server 8080
# откройте http://localhost:8080
```

## Публикация

Сайт уже развёрнут на **GitHub Pages**:

- Репозиторий: https://github.com/rezuggiden-commits/help-misha
- Сайт: https://rezuggiden-commits.github.io/help-misha/ (HTTPS включён автоматически)

Любое изменение файлов в репозитории (через веб-интерфейс GitHub) автоматически перезаписывает сайт.

### Свой домен (по желанию, бесплатно)

GitHub Pages позволяет подключить свой домен бесплатно:

1. Купите домен у любого регистратора (например, reg.ru — ~200–800 ₽/год).
2. В репозитории: Settings → Pages → в поле **Custom domain** впишите домен → Save.
3. У регистратора добавьте DNS-запись: `CNAME` для `www` → `rezuggiden-commits.github.io` и `A`-записи для корня → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
4. Когда DNS обновится (до суток), включите **Enforce HTTPS** в настройках Pages.
5. Обновите адрес в `config.js` (`site.url`) и в метатегах страниц (поиском по всем файлам замените старый адрес).

## Структура проекта

```
site/
├── index.html      — главная (история, прогресс, «Как помочь», отчёты, контакты)
├── story.html      — подробная история
├── gallery.html    — фотогалерея с лайтбоксом
├── reports.html    — отчёты о тратах (таймлайн)
├── contacts.html   — контакты и частые вопросы
├── thanks.html     — страница благодарности после перевода
├── 404.html        — страница ошибки
├── config.js       — ЕДИНЫЙ КОНФИГ: все тексты, суммы, реквизиты, фото
├── css/style.css   — все стили
├── js/main.js      — весь функционал (слайдер, прогресс, копирование, модалка)
└── img/            — фотографии, QR, фавикон, обложка для соцсетей
```
