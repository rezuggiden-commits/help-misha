# Поможем Мише — сайт благотворительного сбора

Тёплый «бумажный» сайт для сбора средств на лечение ребёнка. Без сборки и фреймворков: чистый HTML/CSS/JS, все данные в одном файле `config.js`. Публикуется бесплатно на GitHub Pages по HTTPS.

**Живой сайт:** https://rezuggiden-commits.github.io/help-misha/

---

## Как обновлять сайт

Все тексты, суммы, реквизиты и список фото меняются **в одном файле — [`config.js`](config.js)** (внутри всё подписано комментариями).

### Самый простой способ — прямо в браузере

1. Откройте https://github.com/rezuggiden-commits/help-misha и войдите в аккаунт.
2. Выберите файл `config.js` → нажмите **карандаш** (Edit) справа вверху.
3. Исправьте нужные строки (текст в кавычках, числа — без пробелов).
4. Нажмите **Commit changes** — через 1–2 минуты сайт обновится сам (страницу обновите с Ctrl+F5).

### Что чаще всего меняют

| Что | Где в `config.js` |
|---|---|
| Сколько собрано / цель | `fundraising.raised` и `fundraising.goal` (числа в рублях) |
| Срок сбора | `fundraising.deadline` (пусто `""` — строка скроется) |
| Короткий текст на главной | `child.shortStory` |
| Полная история (по абзацам) | список `story` |
| Реквизиты (карта, счёт, СБП) | раздел `donate` |
| Контакты (телефон, Telegram, WhatsApp, почта) | раздел `contacts` |
| Отчёты о тратах | список `reports` (новые добавляйте сверху) |
| Кто организует сбор (для футера) | раздел `legal` |

## Фотографии — папка `photos/`

Все фото лежат в папке **`photos/`**. Сейчас там плейсхолдеры с подсказками («сюда загрузите настоящее фото…»).

### Заменить плейсхолдер своим фото

1. На GitHub откройте папку `photos` → **Add file → Upload files**.
2. Загрузите свой файл **под тем же именем**: `photo-1.jpg`, `photo-2.jpg` … — он сам встанет на место плейсхолдера (в слайдер на главной и в галерею).
3. Подсказку под фото («что здесь должно быть») и описание для поисковиков можно поменять в `config.js`, список `photos`:

```js
{ file: "photos/photo-1.jpg", hint: "Мишин портрет", alt: "Фото Миши" },
```

4. Чтобы добавить ещё одно фото — загрузите файл (например `photo-7.jpg`) и допишите строку в список `photos`. Первые три фото попадают в слайдер на главной.

Рекомендуемый размер — до 1600 px по ширине, формат JPG.

### Чеки для отчётов

Загрузите фото чека в `photos/` (например `receipt-oct.jpg`) и укажите его в отчёте:

```js
{
  date: "2026-10-01",
  title: "Название отчёта",
  text: "Что оплачено и на какую сумму.",
  image: "photos/receipt-oct.jpg",   // или "" если без документа
},
```

### Отключить записку «Режим настройки»

Пока в `config.js` стоит `demo: true`, сверху видна жёлтая записка о шаблонных данных. Когда замените всё на настоящее — поставьте `demo: false`.

## Способы оплаты

Все способы уже оформлены (кнопка «Помочь» и раздел «Как помочь»):

1. **СБП по QR-коду** — основной способ. QR сейчас — заглушка (`img/sbp-qr.png`).
   **Заменить:** в приложении банка → «Получить перевод по СБП» → сохранить QR → загрузить в `img/` вместо `sbp-qr.png`. Если банк даёт ссылку вида `https://qr.nspk.ru/...` — вставьте её в `donate.sbp.link`, на сайте появится кнопка «Оплатить по ссылке СБП».
2. **На карту** — номер карты и телефон для перевода по СБП, с кнопкой «Скопировать» (`donate.card`).
3. **По реквизитам** — счёт, банк, БИК, ИНН, назначение платежа (`donate.requisites`). Ненужные поля можно удалить.
4. **ЮMoney** (необязательно) — `donate.yumoney.enabled: true` + ссылка с yoomoney.ru.

### Честно о полноценном эквайринге

Приём карт «как в интернет-магазинах» (виджет ЮKassa, CloudPayments, Robokassa, Тинькофф) требует договора с платёжным провайдером и статуса ИП / ООО / самозанятого (либо договора с фондом). Сейчас сайт использует честную схему **СБП QR + карта + реквизиты** — деньги приходят напрямую получателю, без комиссий посредников. Когда появится договор — блок для кнопки провайдера легко добавить в раздел `donate` (по образцу `yumoney`).

## Структура проекта

```
site/
├── index.html      — главная (слайдер, прогресс, «Как помочь», отчёты, контакты)
├── story.html      — подробная история
├── gallery.html    — фотогалерея с лайтбоксом
├── reports.html    — отчёты о тратах (таймлайн)
├── contacts.html   — контакты и частые вопросы
├── thanks.html     — страница благодарности после перевода
├── 404.html        — страница ошибки
├── config.js       — ЕДИНЫЙ КОНФИГ: тексты, суммы, реквизиты, список фото
├── css/
│   ├── style.css   — все стили
│   └── fonts.css   — подключение шрифтов (Podkova, Golos Text, Caveat)
├── js/main.js      — весь функционал (слайдер, прогресс, копирование, модалка)
├── photos/         — ФОТО САЙТА (заменяйте файлы здесь)
├── fonts/          — шрифты (self-hosted, обновлять не нужно)
└── img/            — служебные картинки: QR СБП, обложка для соцсетей, фавикон
```

## Публикация

Сайт развёрнут на **GitHub Pages**:

- Репозиторий: https://github.com/rezuggiden-commits/help-misha
- Сайт: https://rezuggiden-commits.github.io/help-misha/ (HTTPS включён автоматически)

Любое изменение файлов в репозитории автоматически перезаписывает сайт.

### Свой домен (по желанию, бесплатно)

1. Купите домен у любого регистратора.
2. В репозитории: Settings → Pages → **Custom domain** → впишите домен → Save.
3. У регистратора: `CNAME` для `www` → `rezuggiden-commits.github.io`; `A`-записи для корня → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
4. Когда DNS обновится (до суток) — включите **Enforce HTTPS** в настройках Pages.
5. Замените адрес в `config.js` (`site.url`) и в метатегах страниц.
